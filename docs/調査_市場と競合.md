# 調査：市場と競合（2026-08-30）

出典URL付き。確認できなかったことは「不明」と明記。推測を事実として書かない。

---

## 0. 結論を先に

**戦ってはいけない領域と、空いている穴が、はっきり分かれた。**

| | |
|---|---|
| 🔴 捨てる | 公共土木の電子納品XML／電子小黒板の改ざん検知／AI工種分類／チャット・図面・工程 |
| ✅ 狙う | **レイアウトを保ったままのExcel出力**／**レイアウトの自由度**／**HEIC**／**アカウント不要で即完成品** |

### この調査でいちばん価値のある1行

> **電子小黒板利用者1,656社への調査（2022年1月・株式会社ルクレ＝蔵衛門の提供元）で、
> 「台帳作成の負担は**半数がデジカメの頃と変わらない**」という結果が出ている。**

出典: https://www.kuraemon.com/special/kokuban_research/

**撮影は楽になったが、台帳を組み立てる工程は解決されていない。** それをツール提供者自身の調査が言っている。ここが我々の土俵。

## 1. 🔴 戦ってはいけない領域（技術的・構造的に個人では無理）

| 領域 | なぜ無理か |
|---|---|
| **電子小黒板の改ざん検知** | J-COMSIA の「信憑性確認（改ざん検知機能）検定」合格が必要で、**CRYPTREC暗号リスト記載の暗号技術の使用が必須**。合格ソフトは既に251件以上。個人が検定を通すコストは非現実的 |
| **電子納品XML出力** | デジタル写真管理情報基準は PHOTO.XML / PIC / DRA のフォルダ構成、`Pnnnnnnn.JPG` 命名、有効画素数、写真編集禁止を規定。**国交省・農水省・NEXCO・首都高・各自治体で別々に、毎年改訂**。蔵衛門御用達DXは「契約中は自動更新で常に最新要領対応」を売りにしている土俵 |
| **AI工種自動分類** | 蔵衛門は26年で蓄積した**12億枚超**の工事写真を学習データに約1,500パターンの仕分けAI。現場フォトクラウドは22工種・9施工段階を**無料枠から**提供 |
| **黒板テンプレートの物量** | 蔵衛門 約5,000種／ANDPAD CSVで数千件一括／蔵衛門御用達 12,096工種の分類マスター |
| **チャット・図面・BIM・工程表・原価** | CheXのレビュー「多機能すぎて使い切れない」がすべて。1人でやると全部が中途半端になる |

→ **公共工事の土木は入口で詰む。民間工事・リフォーム・設備・内装・点検の報告書に絞る。**
そこは「発注者が要領を指定しない、でも写真台帳は要る」領域で、**Excelと無料テンプレが支配していて、SaaS各社は施工管理プラットフォームを売りたいので取りこぼしている。**

## 2. ✅ どこも埋めていない穴（確度の高い順）

| # | 穴 | 根拠 |
|---|---|---|
| 1 | **アルバムレイアウトを保ったままの .xlsx 出力** | 蔵衛門は公式ヘルプで「アルバムレイアウトのままのExcel出力は不可、PDFかビューワで」と明言。ミライ工事は月990円以上。多くはPDF止まり。**「客先がExcelで欲しがる」現実に対して無料で埋めている製品が無い** |
| 2 | **台帳レイアウトの自由編集**（1ページ何枚・枠サイズ・記入欄の位置） | Photoruction のレビューに「**台帳や検査写真の大きさを変更できない**」。一方、無料Excelテンプレは 2/3/4/6/8/12枚 が流通＝**現場が求めるのはこの粒度**。SaaSが固定でExcelが自由という逆転が起きている |
| 3 | **重複・ブレ・ピンボケの自動検出** | **建設業向け製品で謳っているものが1つも見つからなかった。** 現場では同じ構図を保険で3枚撮るのが常識 |
| 4 | **HEICのネイティブ処理** | 蔵衛門御用達は**公式に非対応**（ユーザーに変換を要求）。他社は記載自体がなく不明。**iPhoneの標準設定がHEIC** |
| 5 | **アカウント不要・インストール不要で完結** | ほぼ全製品が「アプリを入れて、現場を作って、メンバーを招待して」から始まる。ANDPADのレビュー「**業者さんとの写真やりとりはやはりLINEなどが便利で、結局そちらを使ってしまいます**」は導入摩擦の敗北宣言 |
| 6 | **料金の透明性** | ANDPAD / KANNA有料 / CheX / SPIDERPLUS / Photoruction が**すべて「要問い合わせ」**。CheXレビュー「投資判断が困難」 |
| 7 | 表紙・目次・ページ番号の自動生成 | PC買い切りソフトにはあるが、**クラウド/スマホ系での明記が見つからない** |
| 8 | 地図上での撮影位置表示 | CIMPHONY Plus と どこでも写真管理Plus 以外で確認できず。**EXIFのGPSは全端末が持っているのに活用されていない** |

## 3. レビューに出ている「不満」（＝我々の仕様書）

**ミライ工事**（App Store 3,042件）
- 「**とにかく重い。発熱するし動作も遅い**」「遅い、消える、固まるの3拍子」
- 「**写真を1枚削除するのに30秒の動画を観なければならない**」（無料版の広告）
- 「**写真が保存されない不具合**」「写真を削除するのにまとめてできない」

**Photoruction** … 「台帳や検査写真の**大きさを変更できない**」
**ANDPAD**（207件・価格3.6/5） … 「通知が毎日鳴り止みません」「**結局LINEを使ってしまいます**」
**SPIDERPLUS**（App Store 2.8/5） … 「ファイル移動やテンプレート編集ができない」
**CheX** … 「**多機能すぎて使い切れない**」
**蔵衛門** … 「**iPhoneのみでしか使用できず、Androidでは使えない**」（公式に裏取り済み）

**Excel運用そのものへの不満 ← これが本当の競合**
- 「配筋検査30枚で1枚ずつ挿入→サイズ調整→入力。**30枚やったら2時間が消えた**」
- 「スマホ写真は1枚3〜5MB。10枚以上貼ると**数十MBになりフリーズ**」「3物件分で50MB、メール添付不可」
- 「画面上では揃っていた写真が、**印刷すると枠からはみ出したり、最後の1枚が次のページに送られたり**」

## 5. 都合の悪い事実

1. **市場は混雑している。** 確認できただけで15製品以上。
2. **支払意思額の天井が月500〜1,000円。** しかも無料の競合が既にいる。
3. **中小建設業60社への調査で、電子小黒板・情報共有システムは「ほとんどの企業で導入」済み**（JICE REPORT）。空白地帯ではない。
4. **建設業の個人業者は20年で57%減**（158,227→67,780業者）。狙う母集団が縮小中。
5. **「30枚で2時間」の出典の多くはベンダー**（ツールを売る側）。誇張のインセンティブがある。中立な公的統計で「写真整理に◯時間」を示すものは**見つからなかった**。
6. **建設以外の業界（清掃・害虫駆除・浄化槽・造園・農業）の生の「報告書が大変」という声は、ほぼ発見できなかった。** 需要が無い証拠ではないが、**ある証拠でもない。**
