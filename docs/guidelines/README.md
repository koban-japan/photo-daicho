## 全体を通して分かったこと

### 1. 「1ページ6枚」は業界標準ではなかった

**明文で枚数を定めている一次情報は3つだけで、いずれも6枚ではない。**

| 出典 | 枚数 |
|---|---|
| 国交省 12条点検の別添2様式 | **2枚**（様式にブロックが2組印刷されている） |
| 猪名川町 工事写真帳作成要領 | 「**1ページに掲載する写真の数は2〜3枚とする**」 |
| 埼玉県 石綿の自己点検表 写真頁 | **8枚** |

営繕工事写真撮影要領・写真管理基準（案）・石綿のマニュアルには**枚数の規定が無い**。
→ **6枚固定をやめてレイアウトを可変にしたのは正しかった。** 主力は 2枚・3枚。

### 2. 前後対比を制度が要求しているのは「除草」と「補助金リフォーム」

- **除草**：調べた自治体の特記仕様書が**全件**「同一箇所・同一アングルでの対比」を明文で要求
- **補助金リフォーム**：国の3事業すべてが「同じ画角」を要求。**撮り忘れると金が出ない**

一方、**12条点検と災害・保険は前後対比を要求していない**。太陽光は推奨止まり。
→ **「前後をペアで並べる」機能は、除草と補助金リフォームのテンプレートにだけ出す。**

### 3. 撮影日時の扱いが業種で正反対

| 業種 | 撮影日時 |
|---|---|
| **石綿除去** | **法的に必須**（通達「撮影場所、撮影日時等が特定できるように記録する必要がある」） |
| 除草（市川市） | 「**写真に日付を写しこむこと**」 |
| 太陽光O&M（v3の実務） | 🔴 **「撮影時刻を自動で書き込まない」が temma の明示的な指示** |
| 補助金（給湯省エネ） | 契約日が古い場合のみ工事看板。「**画像編集により日付等を入れることは認められません**」 |

🔴 **v3の「撮影時刻を書かない」は太陽光O&Mの実務指示であって、全業種の規則ではない。**
テンプレートごとに切り替えられる必要がある。

### 4. 「写真の編集禁止」が公共では明文

営繕工事写真撮影要領4.：「**工事写真の編集を行ってはならない。** ただし、小黒板情報の電子的記入はこれにあたらない」
写真管理基準（案）も同旨。給湯省エネも「画像編集により日付等を入れることは認められません」。

→ **本アプリは写真に何も描き込まない（縮小のみ）。この設計は公共案件でも安全側。**
→ 逆に**機能案P3-14「写真への矢印・赤線の書き込み」は、公共工事では禁じ手になる。** 実装するなら12条点検（神奈川の記入例が「必要に応じて矢印等を加筆」と明記）に限定し、公共土木・営繕では使えないと明示すること。

### 5. 縮小して貼るのは要求と一致している

- 営繕要領：**100万〜300万画素程度（1,200×900〜2,000×1,500ピクセル程度）**、JPEG、カラー
- 京都市（12条点検の電子提出）：「解像度が高すぎる写真を添付すると、エクセルファイルのファイル容量が大きくなり、**電子申請で提出することができません**」

→ 本アプリの **EMBED_MAX = 1200px** は営繕要領の下限にちょうど一致。**「軽い」は実務上の要求であって手抜きではない。**

### 6. 台帳が要らない領域がある

**国の補助金3事業は台帳形式を原則禁止**し、1枚ずつのアップロードを求める（→ [補助金リフォーム.md](補助金リフォーム.md) §0）。
台帳が要るのは ①国の一括申請 ②自治体の補助金 の2場面だけ。

→ **「補助金申請に使えます」と単純に謳ってはいけない。**

### 7. 無料の公式アプリが存在する領域がある

住宅省エネ2026キャンペーンは**無料の工事写真撮影アプリ**を配布している（位置情報・日時つき、編集不可）。
ただし**そのアプリは台帳を作らない**ので、自治体申請向けの台帳化には穴が残る。

## テンプレート設計への反映（→ `js/templates.js`）

この調査から、テンプレートが持つべき軸は5つと確定した：

1. **perPage** — 2/3/4/6（業種で違う。6枚は「決まった様式が無いとき」の汎用）
2. **fields** — ヘッダー4項目のラベル（現場名/作業種別… は太陽光の形。業種で変わる）
3. **noteHints** — 記入欄の見出し（12条点検＝部位・番号／調査項目／特記事項、塗装＝面／工程名／塗料名）
4. **checklist** — 撮影項目。**出典のある項目だけ**を載せる
5. **pair** — 前後対比モードを出すか（除草・補助金リフォームのみ true）

> ⚠️ **本アプリのテンプレートは、公的様式そのものの再現ではない。** 12条点検の別添2様式も、補助金の指定台紙も、構造が違う。
> **「その様式で提出できます」とは言わないこと。** 言えるのは「その業種で必要とされる写真を、漏れなく並べた台帳が作れます」まで。
