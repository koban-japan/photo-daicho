# 太陽光発電所のO&M（保守点検）の記録写真

調査日 2026-09-01 ／ 法令原文（e-Gov）・資源エネルギー庁ガイドライン・JEMA/JPEA技術資料に当たって確認

---

## 0. 結論：**法令は写真を要求していない。ただし記録・保管は法令義務**

これは当初の想定（「写真要求を確認できず＝要求が弱い」）より一段精密な結論。

| | |
|---|---|
| **写真の義務** | **無い。** 事業計画策定ガイドライン・再エネ特措法施行規則・電気事業法施行規則のいずれにも、点検記録への写真添付の要求は存在しない |
| **記録・保管の義務** | **有る。** 再エネ特措法施行規則第5条第1項第3号。「大臣の求めに応じて提出できる状態」を要求 |
| **様式・頻度・黒板・枚数** | **一切の指定なし**（＝公共工事との本質的な差はここ） |
| 写真の位置づけ | JEMA/JPEA ガイドラインが**推奨**レベルで2箇所に規定（竣工比較・植生記録） |

> 💡 **売り文句への含意**：「法令で義務」とは言えない。言えるのは「**記録は法令義務。その記録を作る手間を減らす**」まで。誇張しないこと。

## 1. 検証の内容（なぜ「写真の義務は無い」と言えるか）

### 事業計画策定ガイドライン（太陽光発電）2026年4月改訂版が現行

本文全文をテキスト抽出して「写真」を全件検索した結果、**保守点検・維持管理の文脈に「写真」は1件も出現しない**。「写真」が出てくるのは以下の3箇所だけで、いずれも点検とは無関係：

- 屋根設置太陽光の**認定申請・運転開始時**に「太陽電池の全てが屋根に設けられていることを示す図面及び外観写真」を提出（区分認定の要件）
- 自家消費比率の担保として「PCS に表示される発電電力量を写真で保存するなど」（記録手段の**例示のひとつ**であり写真の義務ではない）

保守点検に関する義務規定（第2章第3節「運用・管理」）：
> ⑤ 実施した保守点検及び維持管理の内容について記録・保管すること。〔再エネ特措法施行規則第 5 条第 1 項第 3 号〕

解説：
> 適切に実施していることを示すために、実施した保守点検及び維持管理の内容について記録・保管し、経済産業大臣の求めに応じて、提出できるようにしておくことが必要である。

保守点検計画に定めるべき事項の例示にも「保守点検及び維持管理**結果の記録方法**」とあるだけで、写真の指定はない。

### 電気事業法施行規則第50条（保安規程）

e-Gov 法令 API から全文取得して確認。記録に関するのは第3号（巡視・点検及び検査）、第7号（保安についての記録）、第8号（法定自主検査等の記録の保存）。
**「写真」の語は電気事業法施行規則全体で1件のみ**（第104条系の伐採植物に関する規定）で、太陽光の保安・点検とは無関係。

> ⚠️ ただし**保安規程は事業者が自ら作成・届出するもの**なので、**自社の保安規程に「点検時に写真を撮る」と書けば、それは自らに課した遵守義務になる**（法令由来ではなく自主保安由来）。

### JEMA/JPEA「太陽光発電システム保守点検ガイドライン」JM19Z001 第2版

**点検報告書（9.1）に記載しなければならない情報の列挙に、写真は含まれていない**：
> － 当該システムを説明する概要情報（名称，住所，その他）
> － 検査及び試験を実施した，回路及び設備のリスト
> － 点検記録
> － 試験を実施した回路毎の試験結果の記録
> － 当該点検を実施した責任者の署名

一方、**写真が「推奨」として登場する箇所は4つ**（shall ではなく「望ましい／有効」）：

| 箇所 | 内容 | 強さ |
|---|---|---|
| 4.6 架台・基礎の設計情報 | 「施工記録（施工経過の写真など）も提供することが望ましい」 | 望ましい |
| **11.3 植生管理** | 「検査時に，植生の成長の具合を書き記し，**写真を使って記録する**」 | 手順として記載 |
| **12.4 注記** | 「**竣工検査時に写真を撮り，保守検査の度に竣工検査時との外見上の違いの有無について記録を残すことを推奨する**」 | 推奨 |
| 12.4 b) | 大規模システムでは「航空写真，小型無人航空機（ドローン）による撮影で問題を特定できる場合もある」 | 手段の例示 |

🔴 **写真を最も明確に位置づけているのは「竣工時と定期点検時の外観比較」と「植生（雑草）の成長記録」の2つ。**
→ **これが太陽光テンプレートの骨格になる。**

## 2. FIT/FIP認定事業者に課される保守点検の義務

**計画・体制（運転開始前）**
1. 保守点検及び維持管理計画を策定〔施行規則5条1項3号〕
2. 実施体制を構築。電気主任技術者（小規模事業用電気工作物では保守管理担当者）を含める〔同3号・14号〕
3. 事故・運転停止・発電量低下時の対応方針を関係者間で事前に定める〔同3号〕
4. 民間団体のガイドライン（＝JEMA/JPEA）と**同等以上**の内容とするよう努める（努力義務）
5. 計画を**事業実施期間にわたって保管**〔同3号〕

**運用段階**
1. 計画に則って実施し、**実施状況および結果を定期的に報告**〔同3号・7号〕→ 定期報告（運転費用報告）で
2. 技術基準適合維持義務（電気事業法39条）。50kW以上は保安規程遵守
3. **実施した保守点検及び維持管理の内容について記録・保管**〔同3号〕
4. 発電電力量を計測し記録するよう努める（努力義務）
5. 除草剤利用等で地域住民・周辺環境に影響が及ばないよう努める

**実施体制の目安**：解説で「故障後3ヶ月以内を目途として修理が可能な体制とすることが適切」。

**罰則の構造**：記録が無いと「適切な保守点検を行っている」ことを示せず、大臣の求めに応じた提出ができない → 認定基準違反として指導・改善命令・認定取消しの対象になりうる。
**写真がないこと自体を理由に処分される規定は存在しない。**

## 3. 🔴 2025年5月の改正：PCS周囲の枯れ草が技術基準事項になった

**「発電用太陽電池設備に関する技術基準を定める省令及びその解釈に関する逐条解説」令和7年5月15日**（経産省 電力安全課）第三条の解説（原文）：

> 太陽電池発電所の機械器具が故障等で発火した際、周辺に炎を当てると容易に燃え広がる可燃物（**枯れた草木等**）が存在すると、それに飛び火し広範囲に延焼するおそれがあることから（中略）あらかじめ発火の可能性のある機械器具（**パワーコンディショナー等）の周囲の枯れた草木を除去する**、難燃性の防草シートを敷く、砕石を敷き詰めるなどの（中略）延焼防止措置を講じ、**それを適切に維持する**（例えば、防草シートを敷く場合には、**定期的にシートの点検・交換**を行い、劣化によりその機能が損なわれないようにするなど）ことなどがこれに当たる。

2024年の大規模火災事故を受けた改正。**実務への含意：PCS周囲で刈った草を放置する「刈り倒し」が技術基準不適合になり得る。**

→ **PCS周辺の刈草処理後の状態**と**防草シートの劣化状態**は、写真で残す価値が高い新項目。
※ 条文からの解釈であって、「写真を撮れ」と書いてあるわけではない。

## 4. 撮影項目（実務慣行）

**注記：法令要求ではない。業界共通の公式な「撮影項目標準」は存在しない（確認できず）。**
JEMA/JPEAガイドライン箇条11の点検項目（＝何を見るかは規定されている）を骨格にした。

### 全システム共通（11.1.1）
- フェンス・立入禁止対策、**事業情報を掲示した標識（20kW以上は必須）**、立入禁止標識
- 接続箱・集電箱・開閉器・漏電遮断器・電力量計の筐体：施錠状態、外観の腐食・さび・きず・破損
- サイト全体の清掃度（アレイ下・PCS基礎周辺のごみ、可燃物の有無）
- アレイ下の**植生の繁茂**、動物・虫類の侵入の兆候
- 配線ケーブルのきず・破損、電線管・ケーブルラック・固定部の汚れ・さび・腐食
- **地盤の崩壊、擁壁の倒壊、土石流、地すべり、土砂崩れ、外部への土砂流出、柵塀等の損壊**

### 地上設置システム（11.1.3）
- 基礎付近の土壌浸食・地盤沈下・不等沈降・地際腐食・架台多重連結による膨張変形・基礎の洗掘・盛土地盤の崩壊
- モジュール・配線・筐体に干渉している草／灌木
- 追尾装置の方角ずれ
- 外周フェンス（柵・塀）と標識の傾き・損傷、出入口の施錠
- **標識の破損・傾き・印字の視認性**

### パワーコンディショナ・収納盤（11.2.1）
- 基礎・土台のひび割れ、磨耗、貫通性侵食、動物の活動、雨水による土壌洗掘・流失
- 取付ボルトの緩み・損傷
- PCS内外部の目視：水分・げっ歯類・小動物・昆虫・ほこりの侵入痕
- **トルクマーク**の確認
- 注意標識の欠落・色あせ（「欠落している標識、色あせした標識…を文書に記録する」と明記）

### 接続箱・集電箱・断路器・開閉器（11.2.2）
- 接続部の**トルクマークのずれ**／箱内のごみ、水の浸入跡、錆
- 端子・基板・逆流防止ダイオード・ヒューズホルダの**アークによる変色**
- ドアガスケット、ヒンジ、ロック機構

### モジュール・架台
- ガラス表面の汚れ・破損・障害物（落ち葉、影）／フレームの破損・変形、取付固定の緩み
- 配線損傷・緩み・断線／ジャンクションボックスの変形・ケーブル外れ
- **紛失（盗難等）**／架台ボルト・ナットの緩み・脱落、破損・腐食

### 監視・計測系
- 遠隔監視システムの画面（発電量・PCSエラー履歴）／積算発電量、運転履歴
- I-Vカーブ測定、絶縁抵抗、接地抵抗（数値は別紙）

### 異常箇所の3点セット（実務）
O&M報告書のレビュー記事より：
> 「周辺状況が分かる写真、**対象設備の番号が分かる写真**、発電所内の位置関係が分かる写真が必要です。**拡大写真と全体写真がセット**になっていると、修繕指示に使いやすくなります」

対象：パネル割れ、架台腐食、ケーブル損傷、接続箱の浸水跡、雑草の影、排水不良、フェンス破損。

### 発注者が評価する視点（デューデリ・融資審査）
**JPEA・再生可能エネルギー保全技術協会「太陽光発電事業の評価ガイド」3.2.9**：
> ① 発電に支障がある樹木、雑草等の繁茂 ② **外周フェンス等への葛等の蔓性植物の繁茂** ③ **使用禁止薬剤の使用**

3.2.10「**雑草の丈が低い状態で維持されていること**」も評価対象。

## 5. 写真に添える情報

**注記：これも法令要求ではない。** ガイドラインの構造から必要性が導かれる。

点検報告書（9.1）は「検査及び試験を実施した、**回路及び設備のリスト**」「**試験を実施した回路毎の**試験結果の記録」を必須としており、**回路単位（ストリング／PCS単位）で識別できることが前提**。これを支えるのが：

- **4.4 ストリングレイアウト**：「ストリングを3列以上もつPVシステムでは、太陽電池アレイがどのように分割され、ストリングに接続されているかを示すレイアウト図面を提供しなければならない」
- **4.2 システムデータ**：設備IDなどの事業識別番号／定格システム出力／モジュール・PCS製造業者名、型式名、数量／所在住所
- **D.1.2.10**：「回路、保護装置、スイッチ及び端子のすべてが…適切にラベル表示されている」（＝現地に番号ラベルが存在する前提）

**実務で写真に添えられている情報**：列番号／区画（ブロック）／担当PCS番号／接続箱番号／フェンス区間・排水路の位置／ストリング情報。ドローン点検では「異常を検知した位置情報を航空写真に紐づけ」。

> ⚠️ **「アレイ番号・ストリング番号・PCS番号を写真キャプションに書く」ことを明文で定めた公的な様式・規格は確認できず。** 実務上は事業者ごとの報告書フォーマットに委ねられている。

## 6. 2026年時点の制度状況

- **事業計画策定ガイドライン（太陽光発電）は2026年4月改訂版が現行**
- **JEMA/JPEA 保守点検ガイドラインは第2版（JM19Z001、2019-12-27改訂）が現行**（JEMA公開ページで確認。第3版の案内なし）
- **小規模事業用電気工作物**の類型が2023年3月に新設。太陽電池発電所の使用前自己確認は現在**10kW以上2,000kW未満**が対象
- 使用前自主検査・使用前自己確認の方法の解釈は**令和7年5月15日付け 20250428保局第1号**が現行
- **2026年1月14日**、規制改革推進会議GXワーキング・グループで「太陽電池発電設備の使用前自己確認制度について」が議題に（同資料内に写真提出の記述はなし）
- **太陽電池廃棄物の再資源化等の推進に関する法律（令和8年法律第33号）**が2026年5月29日成立・6月5日公布。施行日は未記載（確認できず）。O&Mの写真要件には直接関係しないが、2026年の最大の制度変化

## 7. 確認できなかったこと

- 産業保安監督部が使用前自己確認結果届出書の添付書類として「設備写真」を求めるか（監督部公式ページが403で取得できず）
- JPEA BU145001（2014年版・低圧向け）に「写真」の語が本当に0件か（PDFのフォント埋め込み不備で抽出が不完全な可能性）
- O&M点検写真に付す識別情報（アレイ番号・ストリング番号・PCS番号）を定めた公的様式・規格 → **存在を確認できず**
- 太陽電池廃棄物再資源化推進法の施行日
- 逐条解説の最新版（令和8年7月1日版。PDFが取得できず。上記は令和7年5月15日版）
- 「定期点検は設置1年後、以降4年ごと」という頻度 → **一次文書で裏取りできず。採用しないこと**
