# 機能案（2026-08-30）

`調査_市場と競合.md` と `調査_業界の広がり.md` からの導出。**方針転換：太陽光O&M専用をやめ、現場系の業界全般に広げる。**

---

## 0. 一言でいうと

> **「アプリを入れずに、ブラウザで、iPhoneのHEIC写真をドラッグして、1ページ何枚組みか選んで、PDFとExcelで出す。リンクで渡せる。」**
>
> **これだけを完璧にやる。電子小黒板と電子納品には触らない。**

理由：撮影の便利さは大手が押さえている。しかし**ルクレ（蔵衛門の提供元）自身の1,656社調査で「台帳作成の負担は半数がデジカメの頃と変わらない」**。台帳を組む工程が空いている。

---

## 1. 戦わないと決めたこと（=作らない）

| 機能 | 理由 |
|---|---|
| 電子小黒板（撮影時合成）＋改ざん検知 | J-COMSIA検定が必要（**CRYPTREC暗号必須**）、合格ソフト251件以上。個人には不可能 |
| 電子納品XML出力 | 省庁ごとに別要領＋毎年改訂。蔵衛門御用達DXが「自動更新で常に最新」を売る土俵 |
| AI工種自動分類 | 蔵衛門**12億枚**の学習データ。現場フォトクラウドは無料枠で22工種提供中 |
| チャット・トーク | ANDPADレビューで「通知が鳴り止まない」が不満の筆頭。かつ**LINEに負けている** |
| 図面管理・BIM・工程表・日報・原価 | CheXの「多機能すぎて使い切れない」がすべて |
| iOS/Androidネイティブアプリ | 保守が2倍。**蔵衛門ですらAndroidアプリを出していない**。Webで作ればAndroid・PC・iPhoneが同時に取れる＝蔵衛門が空けている穴に入れる |
| オフライン撮影 | 黒板前提の土木現場の要件。PWAでやると同期バグの温床（ミライ工事の「写真が消える」レビューが実例） |
| チーム・権限管理・同時編集 | 最初の顧客は一人親方と小規模事業者 |

⚠️ **「撮影済み写真への黒板“後付け”合成」は実装可能**（現場Plusも後付け方式）。民間工事ならこれで十分。将来の候補。

## 2. 載せる機能 — 優先順位つき

### 🥇 P1：これが無いと話にならない（MVP）

| # | 機能 | 根拠 |
|---|---|---|
| **1** | **ブラウザにドラッグ&ドロップ → 数十秒で完成品。サインアップ前に見せる** | Excel運用の痛点は「貼り付け→サイズ調整→入力」で**30枚2時間**。既存SaaSは全部「アプリ入れて現場作って招待して」から。ANDPADの「結局LINEを使ってしまう」は導入摩擦の敗北宣言。**大手が構造的に真似しづらい**（プラットフォーム契約を売りたいので匿名導線を作れない） |
| **2** | **HEIC・大量枚数・EXIF回転の確実な処理** | 蔵衛門御用達は**公式にHEIC非対応**でユーザーに変換を強いている。他社は言及すらなし。**iPhoneの初期設定はHEIC**。ここで落ちると①が全部死ぬ |
| **3** | **レイアウトの自由度：1ページ 1/2/3/4/6/8/12枚を選べる** | Photoructionの明示的な不満が「**台帳や検査写真の大きさを変更できない**」。無料Excelテンプレが2〜12枚で流通しているのは**それが現場の実需だから**。SaaSは固定、Excelは自由。この逆転を突く |
| **4** | **レイアウトを保ったままの .xlsx 出力** | 蔵衛門は公式ヘルプで「アルバムレイアウトのままのExcel出力は不可」と明言。ミライ工事は月990円以上。**無料でここを埋めている製品が無い。**「PDFも出るが、Excelでも出る」は小さいが刺さる |
| **5** | **PDF出力** | 客先提出の実質標準 |

### 🥈 P2：差別化の本体

| # | 機能 | 根拠 |
|---|---|---|
| **6** | **同一箇所の「作業前／作業後」を自動で紐づけて2枚1組で出す** ★最大の差別化 | 徳島県の除草仕様書「**同一箇所で施工前・施工状況・施工後を対比させて添付**」／補助金リフォームは工事前・着工・工事後が必須／大阪市要領は「出来形は2枚1組」。**除草・補助金リフォーム・塗装・解体近隣調査・原状回復・災害復旧に横展開できる** |
| **7** | **EXIF（撮影日時・GPS）での自動グルーピングと自動並べ替え** | AIなしで確実に効く。ミライ工事が「並替え作業から解放」と訴求している価値をタダで実装できる |
| **8** | **閲覧専用URLで共有**（相手はアカウント不要・パスワード・有効期限） | URL共有を明記しているのは Photoruction だけ。**台帳PDFのリンクをLINEに貼れる**、が正解 |
| **9** | **重複・ブレ・ピンボケの自動検出** | **建設業向け製品で謳っているものが1つも見つからなかった。** 現場では同じ構図を保険で3枚撮るのが常識 |
| **10** | **撮影項目チェックリスト**（撮り忘れ防止・業種別テンプレ） | 各社「黒板を先に作る」で実現しているが、**黒板を使わないリフォーム・設備・内装・点検向けは空いている**。補助金リフォームは「撮り忘れ＝補助金が出ない」＝**最も強い課金理由** |

## 3. 業種別テンプレート（P3-12の中身）

**「業界を選ぶ」のではなく「テンプレートを増やす」。** 器は共通で、記入欄のラベルと撮影項目だけ差し替える。

| 業種 | 1ページ | 記入欄 | 撮影項目テンプレ |
|---|---|---|---|
| **石綿除去** ★法令で3年保存 | 2〜3枚 | 撮影場所／撮影日時 | 掲示板(近景・遠景)／隔離・セキュリティゾーン／梱包・保管／器具の付着物除去／保護具着用／取り残し確認／仕上清掃後 |
| **除草・造園** | **2枚（前後対比）** | 箇所名 | 施工前／施工状況／施工後 ×箇所数 |
| **補助金リフォーム** ★撮り忘れ＝実損 | 3枚 | 対象箇所／工程 | 工事前（対象箇所すべて）／着工／工事後 |
| **塗装** | 3〜4枚 | 面／工程名／**塗料名** | 施工前／下地処理／下塗／中塗／上塗／完成 |
| **12条点検** | 2枚 | 調査項目番号／指摘内容／場所 | 要是正箇所（**矢印を加筆**） |
| **太陽光O&M** | 6枚 | アレイ/ストリング/PCS番号 | 作業前／作業後／異常箇所／使用薬剤 |
| **災害・保険請求** | 2〜3枚 | 被害箇所 | 全景／**表札**／損害箇所（複数角度） |

## 4. 課金の考え方（要検討）

**価格では絶対に勝てない。** つくるくん月500円、ミライ工事フリーはPDF出力可、PhotoManagerのフリー版は**製品版と同機能を1年間**、工事写真台帳7は**7,990円買い切り**、無料Excelテンプレは無数。
「一人親方は**月1,000円以上の固定費でも負担**」（つくるくん）。

→ **無料で出して、課金は「無いと金が入らない／罰則がある」機能に限定する**のが現実的。
候補：石綿の法定記録テンプレート＋3年保存、補助金リフォームの撮り忘れチェック、前後対比の自動紐づけ。

⚠️ ただし **AI選別を使う以上、API原価がかかる**（台帳1本あたり Haiku 4.5 で約4円）。完全無料は成立しない。**AI機能だけを課金対象にする**のが素直。
