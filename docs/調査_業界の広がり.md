# 調査：現場写真を使う業界の広がり（2026-08-30）

太陽光O&Mに絞らず、現場系の業界全般に広げるための調査。出典URL付き。「不明」は不明と明記。

---

## 0. 結論を先に

**業界を選ぶより、機能軸を選ぶほうが正しい。**

> **差別化の軸は「同一箇所の作業前／作業後を、時点をまたいで自動で紐づける」こと。**

前後対比を要求する業界は **除草・補助金リフォーム・塗装・解体の近隣家屋調査・原状回復・災害復旧** と横に広い。
撮影の便利さ（電子小黒板）は既に大手が押さえている一方、**台帳を組む工程は「半数がデジカメの頃と変わらない」**（→ `調査_市場と競合.md`）。

## 1. 写真が「法令で名指し」されている領域 ★ここが最強

| 業界 | 根拠 | 内容 | 保存 |
|---|---|---|---|
| **石綿（アスベスト）除去** | 石綿則／大防法第18条の23第2項・施行規則第16条の16（2021年4月〜） | **「作業の実施状況を写真等で記録し、3年間保存」**。撮るべき写真が公的文書に列挙済み＝**そのままテンプレートになる**：掲示板（近景・遠景）／隔離・セキュリティゾーン設置状況／梱包・保管状況／器具の付着物除去／保護具着用／取り残し確認／仕上清掃後 | **3年** |
| **特定建築物定期調査（建基法12条）** | 建築基準法第12条 | 「要是正」部分を撮影した写真を**別添2の様式で添付**。指摘部分に**矢印等を加筆**することが例示されている | — |
| **昇降機定期検査** | 建築基準法第12条 | 主索・鎖・ブレーキパッドの写真 | — |

石綿の要求仕様は「**撮影場所・撮影日時が特定できること**」だけで、電子納品のようなXML地獄が無い。解体工事業の許可業者は**69,949社**。

⚠️ ただし石綿則は改正が続く（2026年改正で工作物の事前調査要件が変更）ため、**法令追随の保守コストが個人開発には重い**。

## 2. 「契約上の義務」＝これが無いと金が入らない領域

| 業界 | 根拠 | 強度 |
|---|---|---|
| **補助金リフォーム** | 子育てグリーン住宅支援事業 | 🔴 「**工事前の写真を撮り忘れると補助金の交付を受けることはできません**」。工事前（対象箇所すべて）＋着工＋工事後。**撮り忘れ＝実損**は最も強い課金理由 |
| **自治体委託の除草・河川維持** | 特記仕様書 | 🔴 「工事写真は、**同一箇所で施工前・施工状況・施工後を対比させて添付**し、10箇所…」（徳島県） |
| 公共工事（土木・営繕・電気通信） | 写真管理基準・撮影要領 | 🔴 ただし電子納品XMLが重く、個人開発は入口で詰む |
| 造林補助 | 竣工写真帳が交付申請の必須添付書類 | 🔴 |
| 罹災証明（自己判定方式） | 自治体 | 🔴 全景／表札／被害箇所の写真添付が必須 |
| 火災保険請求 | 保険会社の運用 | ⚠️ 法令義務ではない。表札・建物名／建物全体／損害箇所（複数角度） |

## 3. 慣習にとどまる領域（＝「無いと困る」構造が弱い）

原状回復（国交省ガイドラインは「望ましい」止まり）／解体前の近隣家屋調査（法的義務なし）／外壁塗装の工程写真／清掃・ビルメンの作業報告書／マンション大規模修繕／害虫駆除（記録自体は建築物衛生法で5年保存だが**写真は名指しされていない**）／**太陽光O&M（写真要求を法令・ガイドラインで確認できず＝不明）**

## 5. 業界ごとの体裁の違い

### 1ページ何枚か
公的基準で枚数を定めた文書は**見つからなかった**。実務慣行：

| 枚数 | 用途 |
|---|---|
| **3枚** | 公共工事の事実上の標準（着手前・施工状況・完了を1ページで完結） |
| **2枚** | **施工前後の対比**、微細箇所 |
| 4枚 | 全景＋近景、計測状況＋数値アップ |
| 6枚 | 定型作業の繰り返しをリスト化 |
| 8枚 | 施主への簡易報告 |
| 12枚 | アーカイブ・内部管理 |

### 写真に添える情報（業界差）
| 業界 | 添える情報 |
|---|---|
| 公共土木 | シリアル番号／写真-大分類／写真タイトル／**撮影年月日(CCYY-MM-DD)** |
| 官庁営繕（黒板） | 工事名／工事種目／撮影部位／寸法・規格／撮影時期／施工状況／立会者名 |
| 電気通信工事（小黒板） | 工事名／工種等／**測点(位置)**／設計寸法／実測寸法／略図 |
| **塗装** | 黒板に「面」「工程名」**「塗料名」** |
| **石綿除去** | **撮影場所・撮影日時が特定できること**（動画も可） |
| **特定建築物定期調査** | 調査項目番号／調査結果（要是正）／指摘内容／写真番号／場所。**指摘部分に矢印を加筆** |
| 罹災証明・火災保険 | 全景／**表札**／損害箇所（複数角度） |
| 太陽光O&M | アレイ番号／ストリング番号／PCS番号（＝工事写真の「測点」に相当・二次情報） |

## 6. 現場の生の声（一次情報）

| 証言 | 出典 |
|---|---|
| 「1年間の工事で**約3,500枚**の写真。小規模ならWordで3枚/ページ。管理ソフトや無料ツールで何とかならないか」→ 回答は「Excel」「マクロで自動挿入」。質問者は**「モジュールに貼ればいいのですか？」とVBAが分からず躓いている** | Yahoo!知恵袋 |
| 21歳の施工管理派遣。契約終了直前に「完成図書に写真が必要」と言われ、**施工前・施工中の写真が「全くと言っていいほどありません」** | Yahoo!知恵袋 |
| 「写真をExcelに貼り付けて報告書を作るのって、本当に大変ですよね」— 電波障害工事の現場監督。**自作ツールで写真サイズ自動調整・回転・赤線描画を実装** | note |
| 「写真台帳のフォーマットを毎回作る・写真サイズを調整する・コメントを書く、といった作業に意外と時間がかかります」 | note（土木施工管理） |

⚠️ **建設以外の業界の生の声は、ほぼ発見できなかった。** SEO記事に埋もれるか、そもそもオンラインに書く習慣が薄い。**需要が無い証拠ではないが、ある証拠でもない。**

## 7. 避けるべき業界

| 業界 | 理由 |
|---|---|
| **公共土木（電子納品）** | 要領準拠が重く、**写真の編集が禁止**（便利なリサイズ・自動整形が禁じ手）。蔵衛門・KENTEMが長年寡占 |
| **太陽光O&M（当初案）** | 点検報告書への写真要求が法令・ガイドラインで**確認できなかった**＝「無いと困る」構造が弱い。国内新規導入も縮小局面 |
| **産業廃棄物** | 環境省のチェックリストに**写真を要求する規定が見当たらなかった**。制度の中心は電子マニフェスト(JWNET) |
| **消防設備点検・浄化槽保守** | 点検票の様式が法定で固まっており、**写真欄の有無すら確認できなかった** |
| **農業・林業** | 経営体が減少中（農業5年で22.3%減、林業31.5%減）。写真需要は補助金申請時のみのスポット。**年1〜数回の利用にサブスクは成立しにくい** |
| **原状回復** | 写真は「望ましい」止まり。賃貸管理システムに機能が内包される領域 |
| **補助金リフォーム** | 課金理由は最強だが、**補助金制度は年度で終わる**。単年で消える制度に依存するのは危険 |
