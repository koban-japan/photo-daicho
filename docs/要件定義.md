# 要件定義 — photo-daicho

最終更新 2026-08-30 ／ 決定者 temma

---

## 1. 何を作るか

**現場写真を放り込むと、写真台帳（Excel）が出てくるツール。**
AIが「どれを使うか」と「記入欄に何と書くか」の案を出し、**人間が確定してから**Excelにする。

## 2. 誰が使うか

太陽光発電所のO&M（保守点検）を請けている**小規模事業者**。従業員数人〜一人親方。
Excelで手作業の台帳を作っており、専用ソフトを買うほどではないが1本に半日かかっている層。

想定する使い方：**作業から帰った当日の夜、自宅のPCで作る。** スマホは閲覧のみ。

## 3. 画面の流れ

```
① 現場の情報を入れる（現場名・作業種別・作業日・天候）
        ↓
② 写真を選ぶ（複数・HEIC可）
        ↓
③ [任意] AIに選別と記入欄の文案を頼む
        ↓
④ 確認して直す ← ★ここが本体
     ・チェックを外す／付ける
     ・順番を上下に入れ替える
     ・記入欄3行を自由に書き換える
        ↓
⑤ Excelをダウンロード
```

**③を飛ばして④から手で作れること。** AIが落ちていても、接続先が未設定でも、ツールとして成立する。

## 4. 機能要件

### MVP（ここまでで「使える」）

| # | 要件 |
|---|---|
| F1 | 写真を複数選択できる。**HEIC（iPhone）がそのまま入る** |
| F2 | 読み込んだ写真を一覧で見られる（サムネイル・ファイル名） |
| F3 | 1枚ごとに「使う／使わない」を切り替えられる |
| F4 | 順番を入れ替えられる |
| F5 | 1枚ごとに記入欄3行を編集できる |
| F6 | ヘッダー4項目（現場名・作業種別・作業日・天候）を入れられる |
| F7 | **Excelをダウンロードできる**。レイアウトは §6 の通り |
| F8 | ファイル名が `【作業日】【現場名】　作業種別　写真台帳.xlsx` になる |

### 第2段（AI）

| # | 要件 |
|---|---|
| F9 | コンタクトシート（20枚/1枚）を作ってAIに送り、**使う写真と順番の案**をもらう |
| F10 | 選んだ写真をAIに送り、**記入欄1行目の文案**をもらう |
| F11 | AIの案は**すべて画面で上書きできる**。全部捨てて手で選び直せる |
| F12 | AIへの要望を自由文で渡せる（例「20枚に絞って」「監視カメラは作業後です」） |

### 第3段（商売）

| # | 要件 |
|---|---|
| F13 | 無料は写真10枚まで。超えたら課金へ誘導 |
| F14 | ライセンスキーを入れると無制限になる（**発行は当面手作業でよい**） |

### やらないこと（MVPでは）

- PDF出力（日本語フォント埋め込みが重い。Excelから印刷すれば足りる）
- テンプレート保存・案件管理
- ログイン・アカウント
- 写真の自動タグ付け・自動分類
- スマホでの作成（閲覧はできてよい）

## 5. 受け入れ条件

**MVPの合格ライン**：滑川の19枚（`OneDrive\What Spot\GS滑川発電所\202608_除草作業\写真\_受信\sel`）を入れて出したExcelが、
手作業で作った `【202608】【GS滑川発電所】　除草作業　写真台帳.xlsx` と**レイアウトが一致する**こと。

| # | 確認すること |
|---|---|
| A1 | 1ページに6枚、2列×3段で並ぶ |
| A2 | 写真が枠からはみ出さない。縦横比が崩れない。枠内で中央に来る |
| A3 | ①②③…の番号が写真の**下・右端**にある |
| A4 | 記入欄が3行、**罫線だけの空欄**（ラベルなし） |
| A5 | ヘッダーが**1ページ目だけ**にある |
| A6 | 各ページ下部中央に `1 / 4` 形式のページ番号 |
| A7 | **色が1箇所も使われていない**（黒の細罫線のみ） |
| A8 | 全セルのフォントが `ＭＳ Ｐゴシック` |
| A9 | 19枚入れたら4ページ目まで出る（6+6+6+1） |

**AI機能の合格ライン**：滑川の134枚（`raw`）を入れて、
- B1 実際に採用した19枚のうち**7割以上**をAIも選ぶ
- B2 記入欄の文案が**そのまま使えるか、一語直せば使える**ものが半分以上
- B3 台帳1本あたりのAPI原価が**10円以下**

## 6. Excelのレイアウト（変更不可）

A4縦。列は `A(0.9) / B–E(10.5)＝左の枠 / F(1.4) / G–J(10.5)＝右の枠 / K(0.9)`。

各枠は5行：

| 行 | 高さ | 中身 |
|---|---|---|
| 写真 | 158pt | B:E をマージ。画像を中央配置 |
| 番号 | 17pt | **「画像①」「画像②」…** 右寄せ・indent 1・太字 |
| 記入欄1 | 15pt | 空欄。左寄せ・indentなし |
| 記入欄2 | 15pt | 空欄 |
| 記入欄3 | 15pt | 空欄 |
| （すき間） | 10pt | |

3段ごとに改ページ（2ページ目以降は先頭に10ptのすき間行）。フッターに `&P / &N`。
細部（フォント10pt・余白・行高など）の正は正本Excelと `CLAUDE.md`「レイアウト」。`tools/verify.js` が突き合わせる。

### 絶対にやらないこと

- 写真の上に**題名を置かない**。見出しバーを作らない
- **「備考」というラベルを付けない**
- **撮影時刻を自動で書き込まない**
- **色を使わない**
- **2ページ目以降にヘッダーを出さない**。印刷タイトル行を使わない
- **絵文字を入れない**（PDF化で NotoColorEmoji が埋め込まれる）

## 7. エラー時の挙動

**方針：止まらない。1枚失敗しても残りで進める。**

| 何が起きたら | どうする |
|---|---|
| HEIC変換に失敗した | その1枚だけ飛ばし、**画面に「◯◯.heic は読めませんでした」と名前を出す**。他は続行 |
| 画像が壊れている | 同上 |
| 写真0枚でExcelを押した | ボタンを押せなくしておく |
| チェックが0枚 | 同上 |
| AIの接続先が未設定 | AIボタンを押せなくし、**「手で選んでください」と出す**。エラー扱いにしない |
| AIが失敗した／遅い | **手で選んだ状態はそのまま残す。** 消さない。「AIの呼び出しに失敗しました：〜」と出すだけ |
| AIが選んだ番号が範囲外 | 無視する。落ちない |
| Excel生成に失敗した | メッセージを出す。**入力した内容は消さない** |
| 無料枠を超えた | 生成せずに「無料で出せるのは10枚までです（いまは19枚）」と出す |

**共通ルール：どのエラーでも、temmaが入力した情報（ヘッダー・チェック・記入欄）を消してはいけない。**
やり直しのたびに写真の選び直しから始まるのが、この手のツールで一番腹が立つ挙動なので。

## 8. AIとの約束（入出力）

送り先は Cloudflare Workers（`worker/index.js`）。**APIキーはWorkerだけが持つ。フロントには絶対に置かない。**

### 選別
```
POST /api/suggest
{ "task":"select",
  "context":{"site","work","date","weather","want"},
  "sheets":[{"from":1,"to":20,"image":"<base64 jpeg>"}] }
→ { "picks":[{"n":1,"reason":"作業前 全景"}], "order":[1,5,9], "usage":{...} }
```

### 記入欄の文案
```
{ "task":"caption",
  "context":{...},
  "photos":[{"n":1,"image":"<base64 jpeg>"}] }
→ { "notes":{"1":"", "5":"監視カメラ付近"}, "usage":{...} }
```

**AIは案を出すだけ。** `order` も `notes` も、画面で上書きできる状態を壊さないこと。

## 9. 非機能要件

| 項目 | 要件 |
|---|---|
| **プライバシー** | **写真の原本は端末から出さない。** AIに送るのは長辺520pxの縮小版とコンタクトシートだけ。サーバーに保存しない |
| **コスト** | ホスティング月0円（GitHub Pages）。AI原価は台帳1本10円以下 |
| **動作環境** | Chrome / Edge の最新版。**`index.html` をダブルクリックで動く**（サーバー不要） |
| **性能** | 134枚のHEIC読み込みが**5分以内**。進捗が画面に出ること |
| **依存** | ライブラリは `vendor/` に同梱。実行時に外部から取ってこない |
